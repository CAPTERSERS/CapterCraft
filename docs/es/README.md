# Inicio

CapterCraft es un mod de Minecraft Java para **Fabric** y **NeoForge** que profundiza la supervivencia sin salir de la esencia vanilla.

{% hint style="info" %}
Acompaña a vanilla, no la sustituye. Las herramientas, la armadura y las pepitas de cobre **no** se añaden en 1.21.11: ahí son vanilla.
{% endhint %}

{% columns %}
{% column %}
### Fabric

El mismo contenido. Requiere Fabric Loader y Architectury API.
{% endcolumn %}

{% column %}
### NeoForge

El mismo contenido. Requiere NeoForge y Architectury API.
{% endcolumn %}
{% endcolumns %}
