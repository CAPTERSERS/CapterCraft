# Home

CapterCraft is a Minecraft Java mod for **Fabric** and **NeoForge** that deepens survival without leaving the vanilla feel.

{% hint style="info" %}
Sits alongside vanilla, it does not replace it. Copper tools, armor, and nuggets are **not** added on 1.21.11 — they are vanilla there.
{% endhint %}

{% columns %}
{% column %}
### Fabric

Same mod content. Requires Fabric Loader and Architectury API.
{% endcolumn %}

{% column %}
### NeoForge

Same mod content. Requires NeoForge and Architectury API.
{% endcolumn %}
{% endcolumns %}
