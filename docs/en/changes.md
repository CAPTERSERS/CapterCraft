## 1.0.0

First release on Minecraft 1.21.11. Copper tools, armor, and nuggets are vanilla here, so the mod does not add them.

### Added

- Enderite tools and armor (upgrade netherite at the smithing table)
- Enderite Ingot, Enderite Shard, Block of Enderite
- Void Shard ore in The End (Y 32–80, outer islands)
- Medium Weighted Pressure Plate (75 entities)
- Smelting raw iron, gold, and copper blocks into full blocks
- Enderite Upgrade Smithing Template
- English and Spanish language files

### Technical

- Architectury API 19.0.1+
- Fabric Loader 0.19.5+
- NeoForge 21.11.45+

## 1.0.1

Balance pass so copper gear matches vanilla copper from 1.21.11.

### Changed

- Copper tools: 190 durability (was 180), +1.0 attack bonus (was 1.5), enchantability 13 (was 8)
- Copper axe: 7.0 damage, −3.2 speed
- Copper hoe: −1.0 damage, −2.0 speed
- Copper armor: durability multiplier 11 (helmet 121, chestplate 176, leggings 165, boots 143)
- Copper harvest level matches stone

### Technical

- Architectury API 13.0.8+
- Fabric Loader 0.16.14+
- NeoForge 21.1.191+
{% endupdate %}
