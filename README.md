# ⛏️ CapterCraft

Vanilla, turned up. CapterCraft is a Minecraft Java mod for **Fabric** and **NeoForge** that deepens survival without leaving the vanilla feel.

- 🌐 [Spanish](https://captersersteam.gitbook.io/captercraft/es)
- 🌐 [English](https://captersersteam.gitbook.io/captercraft)
